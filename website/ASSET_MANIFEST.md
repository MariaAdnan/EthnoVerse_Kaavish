# Runtime asset manifest

The following assets are loaded by the built-in 3D tour from the Cloudinary
folder `ethnoverse/3d-tour`: `bangles1 (1)-2.spz`, `bangles2-2.spz`, `box.spz`,
`char_pai.glb`, `desert-v1.glb`, `frame03.glb`, `grass.glb`, `hut.glb`,
`matka.spz`, `mountains.glb`, `oak_trees.glb`, `outfit-2.spz`,
`realistic_bush.glb`, and `rocky.glb`.

The repository does not currently contain item-level creator, license, consent,
or cultural-authority evidence for these files. Their status is therefore
**private research preview only; public redistribution not verified**. Complete
`docs/PUBLICATION_CHECKLIST.md` for each asset before a public deployment.

The generic community placeholder is loaded from this
[Unsplash image](https://images.unsplash.com/photo-1677153224313-7b009d1b33e6)
under the Unsplash license. Replace it with a locally controlled neutral asset
if long-term reproducibility is required.
